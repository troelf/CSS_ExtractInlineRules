HTML file with inline CSS

Inline CSS is not good practice because it mixes presentation with HTML content, makes styles harder to maintain and reuse, and requires editing individual elements whenever the design changes. External stylesheets keep the structure and appearance separate, making the code cleaner and updates more consistent.

Using a stylesheet also improves consistency across a site, allows reuse of the same styles across multiple pages, and makes it easier for teams to collaborate on updates. This separation of structure and design is one of the core principles of maintainable web development.
